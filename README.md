# Inventory and Supplier Analysis (MySQL)

## 📊 Project Overview
This hands-on SQL project explores inventory and supplier data to answer business questions using MySQL.

## 🎯 Project Objectives
- Identify the state with the highest number of suppliers.
- Calculate inventory value by supplier category.
- Practice joining tables and summarizing data with SQL.

## 🔍 Key Findings

### 1. Supplier Analysis by State
Used `COUNT()`, `GROUP BY`, `ORDER BY`, and `LIMIT` to identify the state with the most suppliers.

**Finding:** California had the highest supplier count, with 11 suppliers.

### 2. Inventory Value by Category
Used `INNER JOIN` to combine inventory and supplier data and calculated inventory value using units in stock multiplied by unit cost.

**Finding:** Electronics had the highest inventory value, at $40,000.
